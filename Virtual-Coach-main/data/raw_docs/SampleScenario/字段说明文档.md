# 输入字段说明

## 输入
用户原始文本 (user_text): 字符串类型，用户的自然语言输入

## 输出
| 字段名 | 类型 | 说明 |
|--------|------|------|
| name | string | 用户姓名，如未提供则为 null |
| age | integer | 用户年龄，如未提供则为 null |
| gender | string | 用户性别，"男"/"女"，如未提供则为 null |
| phone | string | 11位手机号，如未提供则为 null |
| email | string | 邮箱地址，需包含@符号，如未提供则为 null |
