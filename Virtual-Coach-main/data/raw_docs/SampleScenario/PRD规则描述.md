# 示例场景：用户基本信息提取

本文和同目录 JSON 均用于演示。联系人为虚构示例，`00000000000` 是不可用于联系的占位号码，只演示 11 位数字格式。

## 任务描述
从用户输入的文本中提取用户的基本信息，包括姓名、年龄、性别、联系方式。

## 输入格式
用户输入一段非结构化的自然语言文本。

## 输出格式
输出一个 JSON 对象，包含以下字段：
- name: 用户姓名
- age: 用户年龄
- gender: 用户性别
- phone: 用户电话号码
- email: 用户邮箱地址

## 注意事项
1. 如果某个字段在输入中未提供，输出中该字段设为 null
2. 年龄必须是整数
3. 手机号需要校验是否为11位数字
4. 邮箱需要包含 @ 符号
