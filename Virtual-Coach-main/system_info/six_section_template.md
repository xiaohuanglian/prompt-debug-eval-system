# Prompt 六板块结构模板

生成的 Prompt 请严格按照以下六个板块组织：

## ROLE
设定 AI 的角色和身份。明确告知 AI 它应该以什么身份/角色来执行任务。

## CONTEXT
提供任务相关的背景信息、上下文和输入数据的字段说明。包括所有输入字段的名称、类型和含义。

## TASK
清晰描述需要完成的具体任务。说明 AI 需要对输入数据做什么处理。

## GENERATION RULES
列出生成回答时需要遵循的规则。包括如何处理边界情况、如何格式化输出等。

## RESTRICTIONS
明确禁止的行为和限制条件。包括禁止询问额外信息、禁止输出无关内容等约束。

## OUTPUT REQUIREMENTS
规定输出的格式。要求 JSON 格式输出，明确每个输出字段的名称、类型和说明。提供输出示例。
